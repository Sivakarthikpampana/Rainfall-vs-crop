# Rainfall-vs-crop
🌾 Crop vs Rainfall Analysis

📊 **Overview**

This project explores the relationship between crop production and rainfall patterns in India. Using historical agricultural and meteorological data, the analysis aims to uncover how varying levels of rainfall influence crop yields across different states and seasons. The goal is to provide actionable insights for policymakers, farmers, and stakeholders in the agriculture sector

🧰 Tools & Technologies

>  Python (Pandas, NumPy, Matplotlib)

> Jupyter Notebook

🔍 Objectives

Clean and preprocess crop and rainfall datasets

Merge datasets based on year and state

Perform exploratory data analysis (EDA) to find trends and correlations

Visualize the impact of rainfall on major crops (e.g., rice, wheat, maize)

Provide region-specific insights to support sustainable farming decisions

📈 Key Insights

Rainfall directly influences the production of water-intensive crops such as rice and sugarcane.

Drought-prone states exhibit unstable crop yields with minimal rainfall deviation.

Seasonal rainfall variation has a measurable effect on crop growth cycles and productivity.
